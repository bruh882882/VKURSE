# README для бэкенд-разработчика

Это руководство объясняет серверную часть сайта «В КУРСЕ» простыми словами.

## 1. Что такое бэкенд в этом проекте

Бэкенд — часть сайта, которая работает на сервере. Она получает запрос из браузера, читает данные, обрабатывает ответы и возвращает страницу.

Используем Python и Flask. Дополнительные серверные фреймворки не нужны.

## 2. Основные файлы

### `app.py` — главный файл

В нём описаны адреса сайта и действия, которые выполняются после отправки форм.

| Адрес | Что делает |
|---|---|
| `/` | Открывает главную страницу |
| `/catalog` | Показывает справочник и применяет фильтры |
| `/sources` | Показывает сводный реестр проверенных первоисточников |
| `/quiz` | Показывает вопросы анкеты |
| `/quiz/result` | Принимает ответы и показывает подборку |
| `/subscribe` | Сохраняет адрес подписчика |
| `/consultation` | Сохраняет обращение студента |

Например, когда браузер открывает `/catalog`, Flask запускает функцию `catalog()`. Она читает JSON-файлы, применяет фильтры и передаёт результат в `catalog.html`.

### `recommendations.py` — правила подбора

Этот файл отвечает только за подбор. Он не рисует страницы и не работает с SQLite.

У программы в JSON может быть блок `match`:

```json
"match": {
  "all": [
    {"field": "mode", "in": ["full"]},
    {"field": "funding", "in": ["budget"]}
  ],
  "any": [
    {"field": "research", "in": ["yes"]},
    {"field": "study_awards", "in": ["yes"]}
  ]
}
```

Это означает: форма обучения обязательно очная, обучение обязательно бюджетное, а среди достижений должно быть научное **или** учебное.

- `all` — каждое условие обязательно.
- `any` — достаточно совпадения хотя бы с одним условием.
- Если блока `match` нет, программа остаётся в справочнике, но не появляется в автоматическом результате.
- Архивные записи не рекомендуются тестом.

### `database.py` — сохранение форм

Этот файл работает с SQLite. В нём создаются две таблицы:

- `subscribers` — адреса подписчиков;
- `consultations` — имя, email и текст обращения.

SQL-запросы используют параметры `?`. Поэтому текст студента передаётся отдельно от команды SQL.

### `config.py` — настройки

Здесь читаются секретный ключ сайта и настройки почты. Секреты хранятся в `.env`, а не в коде.

## 3. Где находится база программ

В папке `data/` лежат JSON-файлы:

- `scholarships.json` — стипендии;
- `support.json` — материальная помощь;
- `grants.json` — гранты и конкурсы;
- `questions.json` — вопросы и ответы анкеты;
- `sources.json` — общий перечень источников.

Чтобы добавить запись:

1. Откройте JSON нужной категории.
2. Скопируйте структуру соседней записи.
3. Укажите новый уникальный `id`.
4. Заполните данные только по официальному источнику.
5. Укажите `lastChecked` — дату фактической проверки.
6. Если сумма или условия спорные, напишите об этом в `note` и поставьте статус `check`.
7. Если правила подбора не подтверждены, не добавляйте `match`.

После обновления JSON внесите те же изменения в Excel-файл базы. Excel помогает команде вести данные, а сайт читает JSON.

## 4. Как проходит подбор

1. Страница `quiz.html` отправляет ответы методом POST.
2. Функция `quiz_result()` проверяет ответы и передаёт их в `make_recommendations()`.
3. `recommendations.py` сравнивает ответы с `match` в каждой программе.
4. Подходящие записи передаются в `result.html`.

Ответы анкеты не сохраняются в SQLite.

## 5. Почтовые уведомления

`send_admin_notification()` использует стандартную библиотеку Python `smtplib`. При заполненном `.env` команда получает письмо о новой подписке или обращении.

Если почтовые параметры не заданы, запись всё равно сохраняется в SQLite. Но автоматическая массовая рассылка подписчикам в проект не входит.

## 6. Запуск

На Windows используйте `start_windows.bat`, на macOS — `start_mac.command`. Скрипты создадут виртуальное окружение и установят Flask.

Для ручного запуска после установки зависимостей:

```bash
python app.py
```

Откройте `http://127.0.0.1:5000`.

## Отдельные автоматические тесты

В папке `tests/` лежит набор автотестов на стандартной библиотеке `unittest`. Запуск: `.venv\Scripts\python.exe -m unittest discover -s tests -v`. Тесты покрывают маршруты, поиск и фильтры, алгоритм подбора, SQLite и целостность JSON. Анкета из 17 вопросов — пользовательская функция сайта. Код бэкенда состоит из небольших функций, которые можно проследить по шагам из этого руководства.

## 7. Что объяснять на защите

1. Flask связывает адрес страницы с Python-функцией.
2. `app.py` читает JSON и передаёт данные в HTML-шаблон.
3. `recommendations.py` сравнивает ответы анкеты с условиями программ.
4. `database.py` сохраняет email и обращения в SQLite.

Это основной серверный цикл проекта. Здесь нет микросервисов, очередей задач и сложной архитектуры.
