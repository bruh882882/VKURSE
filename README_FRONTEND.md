# README для фронтенд-разработчика

Это руководство объясняет пользовательскую часть сайта.

## 1. Что такое фронтенд

Фронтенд — всё, что студент видит в браузере: страницы, тексты, кнопки, формы, цвета и шрифты.

В проекте используются только HTML, CSS и небольшой JavaScript.

## 2. Папка `templates/`

Здесь находятся HTML-шаблоны Flask:

| Файл | Назначение |
|---|---|
| `base.html` | Общая шапка, меню, подвал и подключение CSS/JS |
| `home.html` | Главная страница, подписка и консультация |
| `catalog.html` | Справочник и фильтры |
| `quiz.html` | Вопросы анкеты |
| `result.html` | Результат подбора |
| `message.html` | Простая служебная страница |

Шаблоны используют Jinja — систему вставки данных в HTML.

- `{{ item.title }}` выводит название программы.
- `{% for item in programs %}` повторяет блок для каждой записи.
- `{% if item.note %}` показывает блок только тогда, когда у записи есть примечание.

## 3. Файл `static/css/style.css`

Весь дизайн сайта собран в одном CSS-файле. В начале заданы переменные:

- `--ink` — основной цвет текста;
- `--blue` — синий акцент;
- `--page` — фон страницы;
- `--line` — цвет линий и границ;
- `--radius` — скругление элементов.

Чтобы поменять общий синий цвет, измените `--blue` и при необходимости `--blue-dark`.

В конце файла находятся правила для планшетов и телефонов (`@media`).

## 4. Файл `static/js/main.js`

JavaScript используется только для открытия мобильного меню. Поиск, фильтры, отправка форм и переходы выполняются обычными HTML-формами и Flask.

## 5. Как шаблоны связаны с Flask

Ссылка:

```html
<a href="{{ url_for('catalog') }}">Справочник</a>
```

`url_for` получает адрес по имени функции `catalog()` в `app.py`.

Форма:

```html
<form action="{{ url_for('subscribe') }}" method="post">
```

При отправке браузер передаёт данные на адрес, связанный с функцией `subscribe()`.

## 6. Где менять тексты

- Главная страница: `templates/home.html`.
- Каталог: `templates/catalog.html`.
- Анкета: `templates/quiz.html`.
- Результат: `templates/result.html`.
- Цвета, шрифты и размеры: `static/css/style.css`.
- Вопросы анкеты и варианты ответов: `data/questions.json`.

Суммы, критерии и сроки программ не редактируйте в HTML: они хранятся в JSON, чтобы одна запись использовалась и в каталоге, и в тесте.

## 7. Просмотр изменений

Запустите проект через `start_windows.bat` или `start_mac.command`. Откройте `http://127.0.0.1:5000`.

Изменения HTML и CSS видны после обновления страницы. Если изменили Python-код, перезапустите сервер.
