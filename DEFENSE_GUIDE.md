# Краткое объяснение проекта для защиты

## Что такое «В КУРСЕ»

«В КУРСЕ» — независимый студенческий справочник. Он помогает студентам МАИ находить стипендии, материальную помощь, гранты и конкурсы, изучать условия и переходить к официальным источникам.

## Четыре функции сайта

1. Справочник программ.
2. Анкета для предварительного подбора.
3. Подписка на обновления.
4. Консультация.

## На чём сделан сайт

- Python и Flask — серверная часть.
- HTML — структура страниц.
- CSS — внешний вид.
- JavaScript — мобильное меню.
- JSON — база программ и вопросов.
- SQLite — хранение подписок и обращений.

## Как работает сайт

1. Студент открывает страницу в браузере.
2. Flask принимает запрос и запускает функцию в `app.py`.
3. Сервер читает JSON и передаёт данные в HTML-шаблон.
4. Если студент проходит анкету, `recommendations.py` сравнивает ответы с условиями программ.
5. Если студент отправляет форму, `database.py` сохраняет запись в SQLite.

## Как работает подбор

Вопросы анкеты находятся в `data/questions.json`, а правила для программ — в соответствующих JSON-файлах.

- `all` означает, что должны совпасть все перечисленные условия.
- `any` означает, что достаточно одного совпадения.
- Если условия не подтверждены, программа не включается в автоматический подбор, но остаётся в каталоге.
- Архивные записи не выдаются как рекомендации.

Результат предварительный. Окончательное решение о назначении выплаты принимает МАИ или организатор конкурса.

## Почему данные вынесены в JSON

Суммы, сроки и условия меняются. Если хранить их отдельно от HTML и Python-кода, редактор базы сможет обновить запись без изменения логики сайта.

У каждой программы указываются сумма или пояснение, период, статус, условия, документы, порядок подачи, официальные источники и дата последней проверки.

## Чем проект не является

- Это не официальный сайт МАИ.
- Анкета не подтверждает право на получение выплаты.
- Подписка сохраняет адрес в списке; автоматическая массовая рассылка требует отдельного подключения.
- Почтовые уведомления команде включаются настройкой SMTP.

## Техническая проверка

В проект добавлен набор автотестов на `unittest` (папка `tests/`). Перед демонстрацией запустите их, затем вручную пройдите основные страницы, отправьте тестовую форму и проверьте сохранение заявки в `instance/vkurse.db`.

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```
