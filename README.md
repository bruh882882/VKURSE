# В КУРСЕ — Flask Edition 2026/27

Простой сайт-справочник для студентов МАИ. В проекте четыре функции:

1. Справочник стипендий, материальной помощи, грантов и конкурсов.
2. Анкета для предварительного подбора программ.
3. Подписка на обновления.
4. Форма консультации.

## Что нужно для запуска

- Python 3.10 или новее.
- Flask 3.1.x — устанавливается автоматически из `requirements.txt`.
- SQLite — входит в Python, отдельно устанавливать не нужно.

## Запуск на Windows

1. Распакуйте архив.
2. Дважды нажмите `start_windows.bat`.
3. При первом запуске скрипт создаст папку `.venv` и установит Flask.
4. Откройте в браузере `http://127.0.0.1:5000`.

## Запуск на macOS

1. Откройте Терминал в папке проекта.
2. Выполните `chmod +x start_mac.command`.
3. Запустите `./start_mac.command`.
4. Откройте `http://127.0.0.1:5000`.

Для установки Flask при первом запуске нужен интернет.

## Где находятся данные

Все сведения для каталога хранятся в `data/`:

- `scholarships.json` — стипендии;
- `support.json` — материальная и социальная поддержка;
- `grants.json` — гранты и конкурсы;
- `questions.json` — вопросы анкеты и варианты ответов;
- `sources.json` — общий список источников.

Чтобы обновить запись, откройте нужный JSON-файл, измените подтверждённые сведения и сохраните файл в UTF-8. Не удаляйте запятые, кавычки и фигурные скобки. У каждой записи должен остаться прямой источник и дата последней проверки.

Рабочая Excel-таблица включена в архив: `БАЗА_СТИПЕНДИЙ_2026-27.xlsx`. После проверки обновления внесите одинаковые изменения и в Excel, и в JSON сайта.

## О тестировании проекта

В проект добавлен набор автотестов на стандартной библиотеке `unittest` (без внешних зависимостей). Они проверяют маршруты, поиск и фильтры каталога, валидацию и подбор анкеты, работу SQLite и целостность JSON-данных.

Запуск из корня проекта:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Анкета из 17 вопросов — это функция сайта для студентов, а не средство тестирования кода.

## Формы и почта

Подписка и обращения сохраняются в `instance/vkurse.db`. Чтобы команда получала уведомления о новых записях на почту, скопируйте `.env.example` в `.env` и заполните SMTP-настройки.

Подписка сейчас собирает адреса в список. Автоматическая массовая рассылка писем не реализована. Для неё нужно подключить почтовый сервис и определить порядок отправки.

Без SMTP данные всё равно сохраняются в SQLite, но команда должна просматривать их непосредственно в базе данных. Для консультаций рекомендуется настроить SMTP до демонстрации.

## Перед публичным запуском

Задайте длинный случайный `SECRET_KEY`, включите HTTPS и запускайте сайт через WSGI-сервер, поддерживаемый хостингом. Не публикуйте `.env` и `instance/vkurse.db`.

Подготовьте и проверьте политику обработки персональных данных и текст согласия. В текущем проекте ответы анкеты не сохраняются; в SQLite записываются только данные подписки и обращения.

## Важное уточнение

Результат анкеты — предварительная подсказка, а не решение о назначении выплаты. Студент должен открыть официальный источник и уточнить условия у МАИ или организатора конкурса.
